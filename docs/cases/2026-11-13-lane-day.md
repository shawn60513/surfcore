# 讓她有自己的「此刻」：日程與自我狀態注入

**日期**：2026-11-13
**現象**：問她「在干嘛」「今天做些什麼」，答案永遠是空的或泛泛的（「在發呆」「沒幹嘛」）；
主動開口也只能接最近聊過的事，講不出「我剛在湖邊」「練歌練到一半」這種自己的事。
**根因**：提示詞裡只有三種時間性資訊——現在幾點、上次說話多久前、記憶卡摘要；
**沒有任何「她此刻在哪、在做什麼」**。人設第五章寫了「你自己的日子」，
但那是靜態清單，模型不知道「現在」是哪一項，只好含糊帶過。

**修法**（純本地算，不打 API）：
- 新 `src/lane-day.js`：
  - `PHASES`：sleep 03:00–11:30、wake 11:30–13:00、noon 13:00–14:00、afternoon 14:00–18:00、
    evening 18:00–22:00、night 22:00–03:00（跨午夜）。
  - `daySeed(now)`：FNV-1a 對 `YYYY-M-D` 求雜湊 → 同一天永遠同一份作息，不同天不一樣。
  - `buildDayPlan(now)`：醒來時間抖動（11:30–12:10），下午/傍晚/深夜各排**兩件事**（前半、後半）。
  - `phaseAt(plan, now)` / `currentActivity(plan, now)`：用時段過半與否切前半後半，
    所以 15:00 是「在看別人吃東西」、17:00 變成「在社團幫忙」。
  - `formatSelfLine(activity)` → `（你現在在湖邊：坐在漸湖邊上踩水，風有點涼）`；睡著回空字。
- `src/discord-lane.js`：
  - 加 `dayPlanFor(now)`（按日快取）與 `selfLine(now)`；睡著時改成
    「（你本來在睡覺，被訊息叫醒的）」——半夜被戳醒還講「我在睡」會自相矛盾。
  - `replyPrompt()` 在「你最近在忙」之後插一行；`proactivePrompt()` 同樣插一行。

**驗證**：
- `node scripts/test-lane-day.mjs`：**6 組**（同一天確定、14 天至少 5 種作息、段落切分含跨午夜、
  下午前後半不同事、醒著才有自我狀態、一天內不會只講同一件事）。
- `node scripts/test-discord-lane.mjs`：18 組仍過；`node scripts/test-audit.mjs`：**151/151**。
- 手動跑 `buildDayPlan/currentActivity`：04:00 空白、12:00 剛睡醒、15:00 看吃播、
  17:00 社團幫忙、19:00 看片、21:00 整理相冊、23:00 湖邊、01:00 寫新歌。

**影響面**：只影響 Discord 私訊 lane 的提示詞（每輪多約 30–40 字）。
**遺留**：
- 這是「擬真的固定作息」，不是真的排程——她不會因為在練歌就拒聊，也不會自己記住「今天幾點做了什麼」。
- 清單是手寫的；要更多樣就得往 `AFTERNOON/EVENING/NIGHT` 陣列加，不是每次都會被抽到。
