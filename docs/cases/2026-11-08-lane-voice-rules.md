# Discord lane 语气规则补三条（2026-11-08）

## 现象

用户要「更多真正爱弥斯的感觉」（m05774 / m05940）。已有两轮调过（原话语录、句号过滤、STYLE_SAMPLES），但工作区规则还缺三条从「年轻人聊天习惯」研究里得出的硬规则，她说话仍可能偏「完整、爱追问、把难过的事认真铺开」。

## 根因

- `LANE_WORKSPACE_RULES` 只约束了长度、标点、语气词，没有约束「附和」「追问」和「难过事的表达方式」。
- 这三条是真人感和爱弥斯人设（「小事说成拯救世界，大事轻飘飘一句带过；难过先用玩笑包一层」）里最容易被模型做反的地方：AI 天然爱把附和展开成一句评价、爱连环追问、爱把难过的事郑重地说。

## 修法

`src/discord-lane.js` 的 `LANE_WORKSPACE_RULES` 追加三行：

```
附和要短：「嗯」「哦哦」「真的假的」「笑死」這種，別展開。
每輪最多問一個問題，問完別自己搶著答。
小事可以說成拯救世界，大事反而輕飄飄一句帶過；難過的事先用玩笑包一層，笑完才說一點真的。
```
