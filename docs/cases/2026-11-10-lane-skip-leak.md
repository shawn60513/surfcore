# 2026-11-10 「跳過」被當成回覆發到 Discord

## 现象

用户：「為什麼小愛一直跳過」。DM 里 10:58 她发了一条 **「跳过」**（简体），之前 11-09 凌晨到 11-10 上午一共发过 **9 次**。

## 根因

主动开口那条路上，模型被要求「现在不适合开口就只回一个字：跳過」，代码再用字符串比对把它吞掉：

```js
if (text.replace(/[。！!.…\s]/g, '') !== '跳過') { ...发送... }
```

问题在于**只认繁体**。模型十次里有九次写的是简体「跳过」，比对不相等 → 当成正常内容发出去，还顺手 `pushHistory('bot', text)` 记进历史。于是：

1. 用户收到一条没头没尾的「跳过」；
2. 历史里多了 9 条「跳过」，她下一轮看到自己以前这么说话，就更可能继续这么回（自我强化）。

`nudge()` 里那份同样的判断还有个笔误：`/[。！!.…s]/g`——`s` 少了反斜杠，空白根本没被去掉。

## 修法

- 新增 `export function isSkipReply(text)`：只保留文字（`replace(/[^\p{L}]/gu, '')`），去掉空白、标点、括号、星号、数字后再比对 `跳過 / 跳过 / skip / 不開口 / 不开口`。
- 主动开口与 `nudge()` 两处都改用 `isSkipReply()`，删掉两份手写正则。
- 清理 `state/discord-lane.json`：删掉历史里 9 条 `bot` 的「跳过」（备份 `discord-lane.json.bak-<ts>`），history 48 → 39 条。

## 验证

- `node scripts/test-discord-lane.mjs` → **16 组通过**（第 16 组：简体/标点/括号/星号都算，`跳过吧` 与 `好啊` 不算，空串不算）。
- `node scripts/test-audit.mjs` → 149/149。

## 遗留

- 主动开口本身照旧（`proactive:true`、idle 30 分钟、23–8 点安静）。只是它「不想说话」的时候真的不会再漏出字来。
- 如果以后还看到类似元词（例如「（不開口）」以外的表达），往 `isSkipReply` 的白名单里加词即可。
