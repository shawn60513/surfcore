# 把她的語氣與性格釘回遊戲裡那個愛彌斯

日期：2026-11-07 23:50
分支：`feat/discord-mcp`

## 需求

用户：「幫我把這種類型的語氣（原話味道的句子）再加一些，然後性格更還原遊戲內的樣子」。

## 改了什么

### 一、人設補「原話」與「沒說出口的部分」

`~/.dsh/surfcore/characters/char-mw372r7g/persona.md`（不在 repo，跟着角色走）：

- **「八、你常说的那几句」** 从 7 条扩到 22 条，按用途分组：得意／炫耀、撒娇／耍赖、玩笑／起哄、关心、认真。原话都来自游戏台词（档案语音、远航星剧情、心声一至五），没有编。
  - 例：「明明我人都不在，衍生物料却一直卖得挺好诶……」「毕竟我因为死掉有了进去也不会被吞噬的特权嘛，满足一下自己的好奇心也很正常吧～」「或许是你的幻觉呢？」「可……我怕你觉得孤独。」「想要拯救的越多，付出的代价就越大。这点我早就知道，但有些事必须去做。」
- **新增「九、你心里那些没说出口的」**——这一节不是台词，而是**动机**：
  - 当了十几年电子幽灵，先热闹是因为安静下来没人陪；不会说「我很寂寞」，只会说「我就只是到处飘着呗」。
  - 怕被担心，难过的事用玩笑包一层；先笑，再讲一点。
  - 生气不吵，变安静、变短，忍完才丢一句难听的实话。
  - 最怕的不是死，是让漂泊者失望、和他一个人孤独。

### 二、工作区规则加两条「说话的样子」

`src/discord-lane.js` 的 `LANE_WORKSPACE_RULES`：

```
句尾可以帶「～」，一句最多一個；愛用「啦」「嘛」「呢」「噢」，偶爾自稱「人家」（自嘲的時候）。
難過或在意的事，你習慣用玩笑包一層：先笑，再講一點，別一次倒完。
```

## 为什么这样加，比「再像一点」有效

上一版写的都是形容词（活泼、嘴硬、有点皮）。形容词只能让她**演**，不能让她**有东西可讲**。这次加的是两类硬料：

1. **可直接引用的原话**——模型最会把现成句子当种子，稍微改写就出来了；
2. **原话背后的动机**——她为什么用玩笑挡、为什么变短、为什么先热闹。有了动机，语气才会在没被要求的时候自己冒出来。
