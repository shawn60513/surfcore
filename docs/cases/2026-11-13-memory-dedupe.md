# 記憶卡第一章被寫了兩遍：段落也算「說過的話」

**日期**：2026-11-13

**現象**：`~/.dsh/xingxi/会话/爱弥丝/记忆卡.md` 的「一｜我是誰」出現兩段幾乎一樣的自我介紹
（「我叫爱弥丝。粉头发……」兩遍，第二遍多了電子幽靈幾句）。每輪 brief 都會帶第一章，
等於同一段自我介紹被唸兩次。

**根因**：
- `src/lane-memory.js` 的 `splitChapters()` 只把 `- ` 開頭的條目算進章節內容，
  **普通段落不算**。第一章是整段文字（不是條目），所以去重時看不到它 → 同一段話又被追加一次。
- 去重只有「正規化後完全相同 / 其中包含另一個」。兩段話語序不同（「粉头发，眼睛是暖色的」 vs
  「粉头发，暖色的眼睛」），既不相等也不互相包含，逃過去了。

**修法**（`src/lane-memory.js`）：
- `splitChapters()` 改成「非空行都算這一章的內容」——段落在去重時看得見。
- 新增 `tooSimilar(a, b)`：字元二元組重疊度 ≥ 0.6 就算同一件事（換語序也抓得到），
  只在 `norm.length > 20` 時啟用，避免短句誤殺。
- 新增 `bulletLinesIn()`：**裁剪只動 `- ` 條目**，第一章的段落是身份錨點，不會被當成最舊條目刪掉。
- 資料清理：把卡片第一章的兩段合併成一段（保留含電子幽靈的完整版本）。

**驗證**：
- `node scripts/test-lane-memory.mjs`：**14 組**（新增第 14 組：第一章換語序的近似段落 → `added 0 / skipped 1`；
  真的新內容 → `added 1`；寫完檔案裡「我叫爱弥丝」只出現一次）。
- `node scripts/test-discord-lane.mjs`：19 組（第 19 組是主動開口的四道門，見下）。
- `node scripts/test-audit.mjs`：**151/151**。
- 真機：清理後 `readMemoryBrief()` 回 699 字，開頭只剩一份自我介紹。

**影響面**：只影響寫卡（夜間整理 / 回填）與 brief 內容；不會改到既有條目的順序。

**遺留**：相似度是字元二元組，中文短句很密，門檻 0.6 對「同一件事用不同說法」仍可能漏；
真的重要的話得靠模型在整理時判斷，代碼這層只擋「換句話說同一段」。
